# CleanRit — Official Website

The official landing page for **CleanRit**, an AI-powered Windows PC optimizer engineered for tech enthusiasts on low-end hardware (8GB–12GB RAM).

Inspired by the dark gaming aesthetic of [Hone.gg](https://hone.gg/), tailored specifically for budget rigs, zero telemetry, and 100% open-source transparency.

## Live Hosting
Deployable in 1 click to:
- **GitHub Pages**: Go to Settings -> Pages -> Source: `main` branch `/ (root)` -> Save.
- **Vercel / Cloudflare Pages / Netlify**: Connect this repository with zero build configuration.

## Local Preview
Run locally with Python:
```bash
python serve.py
```
And open `http://localhost:8080`.
